  老年人回忆录 AI 助手 —— 配置与运行说明
  源码基于开源回忆录项目二次开发（Apache 2.0 许可）
══════════════════════════════════════════════════════════════

【这是什么】
- 一个本地运行的 Web 应用：左边是适老化前端界面，右边是 Flask 后端。
- 功能：语音/文字讲述 → AI 整理润色 → 分章节回忆录 → 导出、语音朗读、老照片配文、年轻照还原。
- 数据全部存在本地 data/memoir.json，不上传，不依赖数据库。

【它不是单个 HTML 文件】
- 这是一个需要 Python 运行的“服务器程序”，不是双击就开的网页。
- 但运行后，用浏览器打开 http://localhost:8000 就能用，和打开网页体验一样。
- 想发给别人用，要么让对方也在自己电脑上跑这套（同份源码），
  要么把它部署到 ModelScope 空间 / 云服务器，给一个网址。

【运行前准备：一把密钥（必填，否则 AI 功能不可用）】
------------------------------------------------------------
DASHSCOPE_KEY —— 阿里云百炼(DashScope)密钥
   负责全部 AI 能力：语音识别、文字润色、对话、语音朗读、照片配文。
   获取：登录 https://dashscope.console.aliyun.com → API KEY 管理 → 创建密钥
        → 复制。新用户通常有免费额度。

【怎么跑（三步）】
------------------------------------------------------------
1. 安装 Python 3.10+（官网 https://www.python.org/downloads/ ，
   安装时务必勾选 “Add python.exe to PATH”）。
2. 在本文件夹打开 PowerShell，设置密钥（仅当前窗口有效）：
       $env:DASHSCOPE_KEY="你真实的DashScope密钥"
3. 双击「启动.bat」。看到 “Starting Memoir Assistant on port 8000” 后，
   浏览器打开 http://localhost:8000 即可使用。
   （如需换端口：先 $env:MEMOIR_PORT="8001"，再双击启动.bat。）

【局域网内给家人用】
- 同一 WiFi 下，家人用 http://你的内网IP:8000 也能访问
  （查自己内网 IP：cmd 里 ipconfig，看 IPv4 地址）。
- 想长期对外 / 给异地家人用：部署到 ModelScope 空间或任意云服务器。

【常见问题】
- 没填密钥：页面能打开，但“AI 润色/语音/配文”会报错，这是正常的。
- 端口被占用：设置环境变量 MEMOIR_PORT 为其他端口（如 8001）。
- 数据在哪：本文件夹下的 data/memoir.json，可备份/迁移。

【目录结构】
  app.py            后端服务（Flask）
  dist/             前端页面（已构建，无需再编译）
  requirements.txt  依赖清单
  启动.bat           Windows 一键启动
  data/             回忆录数据（自动生成）
  uploads/ audio/ images/   上传/音频/图片（自动生成）
